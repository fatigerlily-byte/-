# 商品①「仕事まるごとダッシュボード」設計書

## 商品概要
- **価格**: 1,480円
- **ターゲット**: 仕事の全体像を1ページで把握したいビジネスパーソン
- **キャッチコピー**: 「今日やること・進行中・完了」がひと目でわかる、仕事の司令塔

---

## ページ構成（Notionで作る内容）

```
📋 仕事まるごとダッシュボード（トップページ）
├── 📌 今日のフォーカス（シンプルなテキストエリア）
├── 📊 タスク管理DB（メイン）
├── 📁 プロジェクト管理DB
├── 📅 週次レビューDB
└── 📚 メモ・ナレッジDB
```

---

## 各データベース詳細設計

### 1. タスク管理DB（Tasks）

| プロパティ名 | タイプ | 選択肢・設定 |
|------------|--------|------------|
| タスク名 | タイトル | - |
| ステータス | ステータス | 未着手 / 進行中 / 完了 / 保留 |
| 優先度 | セレクト | 🔴 高 / 🟡 中 / 🟢 低 |
| 期限 | 日付 | - |
| プロジェクト | リレーション | プロジェクト管理DBと紐付け |
| 見積時間 | 数値 | 単位: 時間 |
| カテゴリ | マルチセレクト | 会議 / 資料作成 / メール / 確認 / その他 |
| メモ | テキスト | - |

**ビュー設定**:
- ビュー①「今日やること」: 期限=今日 or 優先度=高、ステータス≠完了
- ビュー②「進行中ボード」: ステータス別カンバン
- ビュー③「今週の締切」: 期限=今週、カレンダービュー
- ビュー④「すべてのタスク」: テーブルビュー

---

### 2. プロジェクト管理DB（Projects）

| プロパティ名 | タイプ | 選択肢・設定 |
|------------|--------|------------|
| プロジェクト名 | タイトル | - |
| ステータス | ステータス | 計画中 / 進行中 / 完了 / 中断 |
| 開始日 | 日付 | - |
| 終了予定日 | 日付 | - |
| 担当者 | テキスト | - |
| 進捗率 | 数値 | 0〜100% |
| 関連タスク数 | ロールアップ | Tasks からカウント |
| 概要 | テキスト | - |

**ビュー設定**:
- ビュー①「進行中プロジェクト」: ステータス=進行中
- ビュー②「全プロジェクト一覧」: テーブルビュー

---

### 3. 週次レビューDB（Weekly Reviews）

| プロパティ名 | タイプ | 選択肢・設定 |
|------------|--------|------------|
| 週 | タイトル | 例: 2024年W23 |
| 期間 | 日付 | 範囲設定 |
| 達成できたこと | テキスト | - |
| できなかったこと | テキスト | - |
| 来週の最優先タスク | テキスト | - |
| 気づき・学び | テキスト | - |
| 今週の評価 | セレクト | ⭐ / ⭐⭐ / ⭐⭐⭐ / ⭐⭐⭐⭐ / ⭐⭐⭐⭐⭐ |

---

### 4. メモ・ナレッジDB（Notes）

| プロパティ名 | タイプ | 選択肢・設定 |
|------------|--------|------------|
| タイトル | タイトル | - |
| タグ | マルチセレクト | 仕事 / アイデア / 学び / 参考 / 議事録 |
| 関連プロジェクト | リレーション | プロジェクト管理DBと紐付け |
| 作成日 | 作成日時（自動） | - |
| 重要度 | チェックボックス | - |
